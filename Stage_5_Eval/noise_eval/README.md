# Stage 5 noise/reverb evaluation: index

Start here. This folder measures how the Stage 5 Malay ASR model degrades under far-field noise
and reverb, and compares it with other speech-recognition systems on the same audio.

| Doc | What it is for |
|---|---|
| **`RESULTS.md`** | All numbers. The consolidated all-model table is under **"Full-grid comparison"**. |
| `results_grid/comparison.md` | That same table on its own, regenerated by `results_grid/make_comparison.py` |
| `METHODS.md` | How the code fits together, what a WER number means, why each process decision was made, and the known limitations |
| `HANDOFF.md` | Current state, ranked open items, facts not derivable from the code |
| `FAST_NOTES.md` | How `augment.py` drives the Far-field Audio Synthesis Toolkit (FAST), and its gotchas |
| `../RUNBOOK.md` | Commands: environment, running each model, scoring |

## Experiments

All on one source clip, `mesolitica.wav`: 592 s, 101 utterances, 1,046 reference words. The grid
has 15 cells: RT60 bucket {none, 0.4s, 0.8s} × SNR {none, 20, 10, 5, 0} dB. Each cell has 5
seeded draws, giving 70 degraded files plus clean, 71 in total.

- **Each evidence folder holds:**
  - one normalised transcript per file (`<id>.txt`);
  - the untouched model output (`raw/`);
  - the score tables (`result_*_cells.csv`, `_runs.csv`, `_table.md`).
- **Every table regenerates from these files without any audio;** the commands are in
  `RESULTS.md` → Reproduce.

## Code

| File | Role |
|---|---|
| `augment.py` | Builds the 70 degraded files with FAST: room IR plus stationary noise at a target SNR, seeded |
| `transcribe_many.py` | Runs our model (`../predict.py`) over a manifest, with noisy or oracle VAD |
| `whisper_transcribe.py` | Mesolitica Whisper per oracle segment; `--fallback` is Whisper's standard decoding |
| `gemma_transcribe.py` | Gemma 4 (E2B/E4B/12B) per oracle segment, fp32 or bf16, resumable per segment |
| `gemini_transcribe.py` | Gemini REST (Transcribe or a prompted Flash model); owns `normalise()` |
| `gemini_live_transcribe.py` | Gemini Live WebSocket streaming; `--rebuild` re-derives transcripts from logs |
| `score.py` | Corpus WER per cell with paired two-level bootstrap CIs; `--vs` for paired differences |
| `score_files.py` | Per-file WER for partial or retry sets; flags runaway outputs |
| `wer_utt.py` | Charges each `../wer.py` error to a reference utterance, for the bootstrap |
| `vad_stats.py` | How noisy-VAD segments differ from the oracle segments |

Each script's docstring has its usage and design notes. `METHODS.md` §2 maps how they connect.
